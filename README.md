# Zeroday Tax Consultancy

Premium tax consultancy website for **Zeroday Tax Consultancy**, a Karachi-based firm offering expert tax filing, NTN registration, corporate compliance, and financial advisory services across Pakistan.

## Features

- **Home** — Hero section, service highlights, FAQ, tax calculators, and contact form
- **Brochure** — Standalone web brochure with services overview, accreditations, and mission/vision
- **Company Profile** — Comprehensive profile with consulting areas, service details, and industry coverage
- **Tax Calculators** — Salary tax and withholding tax calculators
- **Coming Soon Pages** — Career, Blog, Events, and FaaS placeholders

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** CSS Modules
- **Icons:** lucide-react
- **Animations:** framer-motion

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build

```bash
npm run build
npm start
```

## Project Structure

```
src/
├── app/                  # Pages (home, brochure, company-profile, career, blog, events, faas)
├── components/           # Reusable components (Navbar, Footer, Hero, About, FAQ, etc.)
└── data/                 # Service data and tax rate tables
```
